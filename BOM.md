# BOM - handwired ZMK Cornedeon

| Component | Specification / Description | Qty | Notes |
| :--- | :--- | :--- | :--- |
| **MCU** | Nice!Nano (nRF52840) | 2 pc | v1 or v2, I use a clone from Aliexpress. |
| **Switches** | Any low profile (Cherry, Gateron, Kailh) | 54 pcs | Chosen by preference (linear, tactile, clicky) |
| **Sockets** | A connector for your switch type, the body is printed on a 3D printer. | 54 pcs | The socket housing differs for different types of switches. Here are my sockets for Kailh Choc v1 and v2. |
| **Diodes** | 1N4148 (through-hole, DO-35 package) | 54 pcs | One diode per switch to prevent ghosting |
| **Battery** | Li-Po 802040, 650 mAh | 2 pc | Turn on Nice!Nano charge boost for battery more 500 mAh. |
| **Power Switch** | Slide switch 20x6 mm | 2 pc | [Ali](https://aliexpress.ru/item/4000699324084.html) |
| **Keycaps** | Low profile keycap set for your switches (mx, choc) | 1 set | On photo - KLP Lame 60 keys MX set. |
| **Wires** | 1-core copper wire PTFE 28 AWG | 3 meters | [Ali](https://aliexpress.ru/item/1005007700772616.html) |
| **Case** | 3D-printed | 1 set | STL files on "case" directory. |
| **Feet** | Silicone self-adhesive bumpons | 8 pcs | Prevents the keyboard from sliding on the desk. |
